### 👋 Hi, I'm Giorgio Frigotto Lovatel

**Senior Software Engineer** · Backend, Payments & Integrations · AI-assisted engineering
📍 Florianópolis, Brazil · 🏢 Company Hero

- Decoupled services: payments, notifications (SMS, WhatsApp, email, push) and e-signature
- Integrations: CRM (HubSpot), external APIs, automation (n8n)
- AI-assisted engineering: parallel agent orchestration with approval and QA gates
